## 🌿 프로젝트 소개 (Overview)

**봄봄놀이터**는 끝없는 경쟁과 바쁜 삶 속에서 지친 춘천 청년 및 쉬었음 청년들을 위한 **온라인 감성 마음 대피소**이자 **로컬 쉼표 커뮤니티 플랫폼**입니다.

나의 마음 온도를 스스로 진단하고, 의암호 그늘 아래 소소한 대화를 나누며 지친 일상에서 벗어나 다시 일어설 따뜻한 힘을 얻어갈 수 있도록 돕는 치유와 연결의 공간입니다.

```
       🏡 춘천 청년 마음 대피소
       ─────────────────────────────────────────────────
       잠시 쉬어가도, 당신의 봄은 늘 따뜻합니다.
       끝없는 경쟁과 바쁜 삶 속에 지친 춘천 청년들을 위한 쉼표 공간입니다.
       나의 마음 온도를 확인하고, 의암호 그늘 아래 소소한 대화를 나누며
       다시 일어설 힘을 얻어가세요.
```

## 💡 기획 배경 및 사회적 가치 (Background & Purpose)

- **쉬었음 청년 지원**: 학업, 구직 활동, 직장 생활 속에서 번아웃(Burnout)이나 고립감을 겪는 청년들에게 심리적 문턱이 낮은 쉼터를 제공합니다.
- **춘천 로컬 자원과의 결합**: 의암호, 공지천, 김유정문학촌, 서면 한옥 북카페 등 춘천 고유의 아름다운 자연과 고즈넉한 힐링 장소를 마음 치유 코스로 연결합니다.
- **지자체 청년 정책 가교**: 춘천시 청년도전지원사업(최대 350만 원 수당 지원) 및 청년 마음건강 바우처 등 실질적인 복지 혜택에 손쉽게 접근할 수 있도록 돕습니다.

## ✨ 주요 기능 (Key Features)

### 1. 🌡️ 마음 온도 자가진단 (Mental Temperature Quiz)
- 간단한 5가지 감성 진단 질문을 통해 현재 나의 마음 온도(15°C ~ 36.5°C)와 심리적 휴식 필요도를 파악합니다.
- 진단 결과에 따라 춘천 로컬 힐링 스팟 추천과 맞춤형 마음 회복 행동 처방전을 제공합니다.

### 2. 🌲 의암호 쉼표 스팟 (Chuncheon Local Healing Spots)
- **물멍 산책**: 의암호 나들길(물레길), 공지천 의암공원 잔디밭
- **숲/초원**: 김유정문학촌 실레마을, 해피초원목장
- **한옥/북카페**: 서면 한옥 소담 북카페, 구봉산 카페거리 테라스
- 카테고리별 필터링, 위치 주소, 힐링 포인트를 상세 안내합니다.

### 3. 💬 소통 놀이터 (Warm Anonymous Wall & Micro-Meetings)
- **익명 온기 방명록**: 회원가입이나 개인정보 입력 없이, 포스트잇 형태로 오늘 하루의 마음 상태를 털어놓고 감정 이모지와 함께 따뜻한 공감(좋아요)을 주고받습니다.
- **춘천 소소한 모임 (느슨한 연대)**:
  - 🚲 *의암호 그늘 아래 자전거 천천히 타기*
  - ☕ *서면 북카페에서 말없는 1시간 독서*
  - 🍕 *공지천 노을 피크닉 & 수다*
  - 부담 없이 참여할 수 있는 소규모 춘천 로컬 쉼표 모임을 신청하고 관리합니다.

### 4. 🃏 오늘의 마음 힐링 카드 (Daily Tarot)
- 인터랙티브 카드 플립(Flip) 애니메이션으로 오늘의 위로 메시지와 함께 소소한 춘천 로컬 힐링 미션(예: *의암호 호숫가 벤치에 앉아 물결 5분간 바라보기*)을 제안받을 수 있습니다.

### 5. 🤝 청년 지원 정보 & 쉼표 안내소 (Youth Policy & Counseling)
- **춘천시 청년도전지원사업**: 지원 자격, 최대 350만 원 참여 수당 혜택, 1:1 맞춤 상담 프로그램 정보 안내 및 고용24 바로가기 링크 제공.
- **긴급 마음 상담 안내**: 자살예방 상담전화 (국번없이 109), 정신건강 상담전화 (1577-0199) 안내.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 사용 기술 | 설명 |
| :--- | :--- | :--- |
| **Core Architecture** | Modern Vanilla JavaScript (ES Modules) | 가볍고 빠른 싱글 페이지 애플리케이션(SPA) 구동 |
| **Styling & UI** | Vanilla CSS3, Glassmorphism design | Custom CSS Variables, 반응형 Grid/Flex, 애니메이션 |
| **Build System** | Vite 8.x | 초고속 HMR 모듈 번들링 및 최적화 빌드 |
| **Typography & Icons** | Outfit, Noto Sans KR, FontAwesome 6 | 감성적이고 또렷한 폰트 및 직관적 아이콘 시스템 |
| **State & Persistence** | Client LocalStorage | 익명 방명록 및 소모임 참가 상태의 백엔드 무의존 보존 |

## 🚀 시작 가이드 (Getting Started)

### 요구 사항 (Prerequisites)
- **Node.js**: v18.0.0 이상 권장
- **npm**: v9.0.0 이상 권장

### 설치 및 로컬 실행 (Installation & Run)

```bash
# 1. 레포지토리 클론
git clone https://github.com/3hongwork-hub/bombomplayground.git

# 2. 프로젝트 디렉토리 이동
cd bombomplayground

# 3. 패키지 설치
npm install

# 4. 로컬 개발 서버 실행 (Vite Dev Server)
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속하여 앱을 확인합니다.

### 프로덕션 빌드 (Production Build)

```bash
# Vite 프로덕션 번들 빌드
npm run build

# 빌드 결과물 미리보기
npm run preview
```

## 🎨 디자인 아키텍처 및 미학 (Design Aesthetics)

- **Warm & Soft Palette**: 피치 핑크(`#FF85A1`), 웜 크림, 미스티 블루, 로컬 그레이 컬러를 조합하여 아늑하고 안전한 마음 대피소의 분위기를 전달합니다.
- **Glassmorphism & Micro-animations**: 카드 호버 시 일어나는 부드러운 상승 효과, 포스트잇 회전 효과, 힐링 타로 카드의 3D 플립 애니메이션 적용.
- **Accessibility & UX**: 모바일/데스크톱 가리지 않는 완벽한 반응형 레이아웃 및 직관적인 하단 탭/헤더 네비게이션.
